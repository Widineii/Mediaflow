# MediaFlow

MediaFlow e um portal de entretenimento criado para reunir jogos de PC, Xbox e PS5, game retro, mangas, filmes e series em uma experiencia unica de catalogo.

O projeto nasceu como uma ideia de site informativo com variedade, capas, filtros, perfil do usuario e uma area para acompanhar ofertas, lancamentos e onde assistir ou comprar cada item.

## Destaques

- Catalogo com jogos, game retro, mangas, filmes e series.
- Interface responsiva com busca, filtros por categoria, plataforma, lancamentos, genero e ordenacao.
- Cards com capas, notas, descricoes, precos simulados e links de consulta.
- Area de promocoes para jogos com comparacao por plataforma.
- Filmes e series com indicacao de onde assistir, sem exibicao de preco.
- Perfil local com cadastro simples, entrada e lista de curtidas.
- Painel de detalhes para cada item, com informacoes, ofertas, streaming e relacionados.
- Catalogo expandido com grande volume de itens para dar sensacao de portal completo.

## Tecnologias

- Java 17
- Spring Boot 3
- Maven
- HTML
- CSS
- JavaScript

## Como abrir

Para visualizar rapidamente, abra o arquivo:

```text
src/main/resources/static/index.html
```

Tambem e possivel rodar como aplicacao Spring Boot:

```bash
./mvnw spring-boot:run
```

Depois acesse:

```text
http://localhost:8080
```

## Objetivo

O objetivo do MediaFlow e funcionar como uma vitrine moderna para descobrir conteudos de entretenimento, comparar informacoes e salvar favoritos em uma experiencia simples, visual e direta.

## Status

Projeto em evolucao. A proxima etapa ideal e conectar APIs reais para manter precos, lancamentos e links sempre atualizados automaticamente.
